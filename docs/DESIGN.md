# 洛天依桌面宠物 · 设计文档 V1.0

> 仅限个人本地使用的 Windows 桌面宠物。双击 exe 运行，数据保存在本机，无需登录。
> 形象为 AI 生成的 Q 版洛天依风格二创（灰发、绿瞳、青色服装），仅供个人观赏。

---

## 一、界面结构（三层）

| 层 | 载体 | 内容 |
|---|---|---|
| 桌面层 | 无边框透明悬浮窗 | Q 版角色、台词气泡、逐句歌词、番茄钟徽章 |
| 菜单层 | 托盘图标右键菜单 | 12 项快捷操作（音乐 / 窗口 / 互动 / 系统四组） |
| 面板层 | 普通设置窗口 | 成长、换装、提醒、通用四个页签 |

## 二、鼠标交互规范

| 操作 | 效果 | 备注 |
|---|---|---|
| 单击 | 随机跳跃 / 抖动 + 台词气泡，好感 +1 | 10 秒内连点不重复计好感 |
| 双击 | 随机播放曲库一首（网易云）+ 逐句歌词 | 唱歌中再双击 = 停止 |
| 按住拖动 | 抓起角色自由移动 | 角色呈"被拎起"姿态 |
| 拖动中快速甩动松开 | 抛出：按甩动方向飞出，重力下落、落地弹跳 1~2 次 | Lv.7 解锁空中旋转 |
| 滚轮 | 缩放角色（50% ~ 200%） | 以角色中心缩放 |
| Ctrl + 滚轮 | 调节透明度（20% ~ 100%） | |
| 右键角色 | 打开与托盘相同的主菜单 | 快捷入口 |

## 三、行为状态机

**日常循环**（无互动时自动运转）：
- 闲逛（默认态）：沿任务栏上沿来回走动，到屏幕边缘折返
- 闲置约 30 秒 → 随机进入：发呆（眨眼放空 5~10 秒）/ 踱步（原地小碎步 8 秒）/ 哼唱（音符特效 + 内置歌词，10~20 秒）
- 连续 2 分钟无操作 → 睡觉（头顶 ZZZ，单击惊醒并闹小脾气）
- 设置项「闲逛时随机真唱」开启后，哼唱有几率变为真唱（在线播放）

**打断态**（任何日常状态下随时触发，结束后回到之前状态）：
- 单击互动（2 秒）/ 双击唱歌（整曲）/ 抓取抛出（物理模拟）/ 系统提醒（约 5 秒）
- 跟随音乐跳舞（系统在放音乐期间持续，详见 3.1）

### 3.1 跟随系统音乐跳舞

- 触发：通过 Windows 系统媒体控制（SMTC）监听——网易云客户端、QQ 音乐、浏览器等任意软件**连续播放音乐 ≥5 秒**
- 条件：功能开启（默认开）且她当前没在唱歌、没被抓在手里 / 被抛出
- 表现：原地跳舞，2~3 套舞步随机切换，偶尔冒气泡（「这首歌不错诶！」「一起摇摆~」）
- 结束：音乐停止 ≥10 秒后回到之前的日常状态
- 互斥规则：唱歌优先——双击点歌时先唱歌，唱完系统音乐还在放则自动接上跳舞
- 依赖：原生模块（系统媒体监听）；加载失败时该功能自动禁用并在设置中标注「不可用」，不影响其他功能
- V1 舞步为固定节奏，不做逐拍同步（V2 考虑音频节拍检测）

## 四、成长系统（两套独立数值）

### 4.1 等级与经验

| 行为 | 经验 |
|---|---|
| 在线陪伴 | +1 / 分钟 |
| 单击互动 | +2 / 次 |
| 听完一首歌（≥60%） | +15 |
| 完成一个番茄钟 | +10 |

升级所需经验：Lv.2 = 120 → Lv.3 = 300 → Lv.4 = 600 → Lv.5 = 1000 → Lv.6 = 1500 → Lv.7 = 2100 → Lv.8 = 2800 → 之后每级 +800

**升级解锁内容：**

| 等级 | 内容 |
|---|---|
| Lv.1 | 初见 · 默认装 |
| Lv.2 | 活泼台词包 |
| Lv.3 | 跳舞动作 + 春日裙 |
| Lv.5 | 星海礼服 |
| Lv.6 | 花式舞步包（跟随音乐跳舞时更多动作变化） |
| Lv.7 | 空中旋转特技（抛出时多转一圈） |

### 4.2 好感度（0~100，影响台词与态度）

| 分值 | 档位 | 表现 |
|---|---|---|
| 0-19 | 陌生 | 礼貌但客气 |
| 20-39 | 熟悉 | 会开玩笑 |
| 40-59 | 朋友 | 主动搭话、关心你 |
| 60-79 | 亲密 | 黏人、撒娇 |
| 80-100 | 挚爱 | 专属台词、每天主动问候 |

来源：单击 +1（每日上限 30）、听完歌 +3、番茄钟完成 +2
衰减：连续 48 小时无互动后每天 -5（最低不低于 0，不会"跑路"）

## 五、台词系统（场景 × 好感度）

每场景每档位 5~8 句随机。示例（点击场景）：
- 陌生：「请…请问有什么事吗？」
- 熟悉：「嘿，主人今天心情不错嘛。」
- 朋友：「摸摸头~ 我唱歌给你听好不好？」
- 亲密：「再摸一下嘛，就一下~」
- 挚爱：「最喜欢主人了！」

其他场景：被抛出（「呀啊——！」/ 高好感是笑闹、低好感是真生气）、唱歌前（「想听我唱歌吗？」）、唱完（「唱得好听吗？」）、惊醒（「唔……再睡五分钟……」）、电量低（「主人！电脑要没电了，快充电！」）、CPU 高负载（「好烫好烫，主人在跑什么大程序呀？」）、久坐（「主人起来活动一下吧~」）、喝水（「喝水时间到！」）。

|---|---|---|---|
| 久坐提醒 | 60 分钟 | 30 / 45 / 60 / 90 | 角色气泡 + 音效 |

| 番茄钟 | 25 分钟专注 + 5 分钟休息 | 时长可自定义 | 角色气泡 + 徽章倒计时，完成 +10 经验 |
| 日程便签 | — | 标题 + 时间，可设每天重复 | 到点角色气泡提醒 |

## 七、点歌与曲库策略

- **选歌方式**：每次点歌从网易云「洛天依」**歌手页的热门歌曲**（约 50 首）里**随机挑一首**——歌单不固定，每次都有新鲜感
  - 歌手页 ID 通过搜索接口自动解析并缓存，不写死
  - 自动过滤 VIP 曲 / 无版权曲，避免点了放不出来
  - 歌曲列表缓存 24 小时，过期自动刷新
- **播放**：网易云公开接口在线流式播放，不下载存盘，无需登录
- **降级链**：歌手页接口失败 → 内置 5 首兜底经典（普通DISCO、达拉崩吧、九九八十一、权御天下、世末歌者）→ 再失败 / 断网 → 哼唱模式（内置歌词 + 音符特效），角色吐槽一句「网络好像不太听话……」
- 预留 voices/ 目录：后续放入洛天依语音文件即可启用点击语音（V2）

## 八、数据存档（本地持久化）

存档位置：exe 同目录 data/profile.json（目录不可写时回退 %APPDATA%\LuoTianyiPet\）。

存档内容：等级、经验、好感度、累计陪伴分钟、互动次数、听歌数、已解锁项、当前服装、位置坐标、全部设置（置顶 / 穿透 / 尺寸 / 透明度 / 自启 / 闲逛真唱 / 提醒配置）、便签列表。

保存时机：每次数值变化防抖保存 + 退出时保存 + 每 5 分钟定时保存。重启电脑不丢。

## 九、技术方案

- **框架**：Electron（无边框透明窗、置顶、鼠标穿透、跨平台动画生态成熟）
- **动画**：AI 生成精灵图（spritesheet），CSS 逐帧动画驱动；帧率 12fps 足够
- **物理**：抛出回弹用简单速度/重力/弹性系数模拟（约 30 行逻辑，无需物理引擎）
- **系统感知**：Battery API（电量）、Node.js CPU 采样（负载）
- **开机自启**：写注册表 Run 键
- **打包**：electron-builder → 单个 portable exe

## 十、第一版里程碑

1. **M1 形象与窗口**：素材生成、悬浮窗（透明 / 置顶 / 穿透 / 缩放 / 透明度）
2. **M2 行为与互动**：状态机、行走、闲置行为、点击 / 拖拽 / 抛出物理、跟随系统音乐跳舞（SMTC）
3. **M3 成长与台词**：等级经验、好感度、台词库、升级解锁
4. **M4 音乐**：歌手页随机选歌、在线播放、逐句歌词、降级哼唱
5. **M5 工具**：提醒四件套、系统感知、托盘菜单、设置窗口
6. **M6 打包**：存档持久化、开机自启、portable exe
